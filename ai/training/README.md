# Model Training

Training code will be added after the final dataset and target crop/disease classes are fixed.

Recommended experiment records:

- Dataset version
- Crop classes
- Disease classes
- Train/validation/test split
- Model architecture
- Input resolution
- Augmentation
- Optimizer
- Learning rate
- Epochs
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- Model size
- Raspberry Pi inference latency

Do not train and test on the same images.
